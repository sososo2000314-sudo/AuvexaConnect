# 機能一覧と実装状況

## UI・基盤に含む
- 初回言語選択（日本語/英語）、設定から変更、選択保存
- PC/スマホ対応の基本レイアウト、ライト/ナイト切替
- ホーム、動画、ショート、公開チャット、メール、フレンド、掲示板、マイチャンネル、設定の入口
- D1テーブル：ユーザー、投稿、コメント、フォロー、公開チャット、個人メッセージ、板、通報、設定
- Worker API：登録（アカウント作成）、投稿一覧/作成、公開チャット取得/送信、フォロー、管理者停止、メンテナンス設定
- 停止期間終了時の自動解除チェック

## 本番化に必要な追加作業
- 安全なログイン/セッション発行とパスワード検証
- 管理者認証のSecret運用・管理UI・監査ログ
- メンテナンス開始前の通知スケジューリングと復旧時刻での自動解除（Cron Trigger等）
- メンテナンス時の全ページ・全API停止と管理者専用復旧経路
- R2署名付きアップロード、容量計測、上限ブロック。Cloudflare請求停止の保証は別途必要
- Durable Objects等によるリアルタイム公開チャット/個人チャット
- WebRTCシグナリング、STUN/TURN、グループ通話
- Web Push、メール配送、Google OAuth
- 災害安否確認の一斉通知、会議申請、板申請の管理ワークフロー
- 動画変換・配信、画像処理、通報/ブロック等の完全なモデレーション

未接続機能を稼働中と偽って表示しないこと。
