# AuvexaConnect / Connect Plus — 完成版開発仕様台帳

## 重要な開発ルール
- この台帳にある機能を、作業の都合で勝手に削除しない。
- 未実装機能を実装済みと表示しない。
- 既存Cloudflare D1テーブルとデータを削除しない。DROP TABLE、TRUNCATE、全消去は禁止。
- DB変更は既存スキーマを調査し、バックアップ後に追加マイグレーションで行う。
- 外部サービスの認証情報はソースに埋め込まず、後から安全に設定できるようにする。
- Mac版を先行し、共通APIを利用してAndroid・iPhone PWA・Connect Plusへ展開する。

## アプリ構成
1. AuvexaConnect Mac（優先開発対象）
2. AuvexaConnect Android
3. AuvexaConnect iPhone（PWA）
4. Connect Plus（別クライアント、共通アカウント／共通API）

## アカウント・認証
- ユーザー名＋パスワードで登録・ログイン。メールアドレス入力は必須にしない。
- ゲストは投稿・動画の閲覧が可能。いいね／評価、コメント、メール、フレンド、通話等は登録後のみ。
- 制限機能をゲストが押したら「この機能を利用するにはアカウント登録またはログインが必要です。」と案内。
- ゲストから通常アカウントへ移行可能。
- Connect IDは5文字、2文字目がA/B/C、残り4文字は数字（例：2A497）。全130,000通り。
- IDはシャッフル生成または空きID一覧から手動選択。確定時にサーバーで重複再確認。
- 公式IDは7A777、表示名は「AuvexaConnect Official」。予約し一般ユーザーの一覧・シャッフルから除外。
- Connect Plus初回の公式管理者パスワードは同形式のランダム値を一度だけ提示。IDと同じ値にしない。平文保存禁止。
- 初回管理者登録はデプロイ時の秘密情報等で保護し、一般ユーザーが先に管理者化できないようにする。
- クイックログイン：対応端末ではFace ID／Touch ID／Android生体認証、非対応時は端末内6桁コード。
- クイックログインは端末固有の安全な保存領域と失効可能なセッショントークンを使用。新端末は通常ログイン。
- 5文字パスワードは組合せ数が少ないため、強いレート制限・ロックアウト・安全なハッシュ化等を必須にする。

## プロフィール・画面・設定
- プロフィールとマイページは同じ画面・入口。
- 投稿のプロフィールアイコンは投稿時の複製ではなく現在のプロフィール画像を表示。
- 日本語／英語切替、ライト／ナイトテーマ（初期ナイト案）、通知、プライバシー設定。
- マイページ項目：世界交流マップ、作品展示、イベント、オンライン教室、百科事典、機能リクエスト、通知センター、設定。
- 便利機能ボタンとアカウント情報を下部に配置。
- 設定内に管理パネル入口。パスワード画面とサーバー側権限検証を必須にする。
- 管理者はデバッグ・メンテナンス時に一般ユーザーの利用を停止できる。
- 右上に現在時刻とサーバー稼働時間を小さく表示。
- アカウント停止時は永久／期限付きの区別と理由を表示。

## 通知
6分類：電話着信、不在着信、フレンド投稿・動画、チャット、劇場・イベント、災害・安全確認。
- 初期状態は全てON。個別変更を保存し、再起動後も維持。
- OS通知許可はセットアップ終盤に要求。アプリ内設定とOS許可を混同しない。
- 災害・安全確認は高優先度表示・強い警告音を目指すが、OS制約を超える保証はしない。
- アプリ終了中・画面消灯中の着信通知や投稿通知はプッシュ基盤・OS設定を接続して実機検証する。
- 更新・メンテナンス通知も用意。

## AuvexaConnect機能
- 投稿フィード、画像・動画リンク、フレンド、チャット、掲示板（「いた」機能を含む）。
- 世界交流マップ、作品展示、イベント、オンライン教室、百科事典、機能リクエスト、通知センター。
- 手動の緊急安全確認メール。自動災害検知とはしない。
- 地域の該当災害情報がない場合も空白にせず、安全ニュース／安全ラジオ欄を表示。
- オンライン教室：教師招待、ホワイトボード、宿題、出席、クイズ、予定、質問、進捗、教材、翻訳、アンケート。

## Connect Plus
- AuvexaConnectとは別アプリ。可能な範囲で共通DB／API・同一アカウントを利用。
- AuvexaConnectのメール入口はConnect Plusを開くか確認し、キャンセルなら元画面に留まる。
- 初回Connect Plus起動時に現在のAuvexaアカウントと連携。電話番号設定はConnect Plus側で行う。
- 内部専用Connect ID、ダイヤルパッド、通話履歴、フレンド通話、不在着信表示、録音・選択式着信音。
- 電話番号は通常の公衆電話網番号ではなくアプリ内識別子。
- メール画面・処理・外部接続口は実装対象。外部メール認証情報は後から設定可能にする。

## 劇場・イベント
- 既存D1劇場専用テーブル50個を保持。削除・再作成しない。
- 劇場作成選択肢は3つのみ：「普通の劇場」「オーディション」「パーティー」。
- 普通の劇場とパーティーは一般ユーザー／公式が作成可能。オーディションは公式ID 7A777のみ作成・主催可能。
- 一般ユーザーはオーディションに応募・観覧可能。
- 審査員は当該オーディションを観覧中の一般観客からランダムに3人選出し、出演者本人を除外。
- ○／△／×の集計合否ルールは最終確定前の提案扱い。確定仕様として固定しない。
- 座席、チケット、反応、上映スケジュール、字幕・翻訳、売店、開演演出、招待・非公開劇場、上映後レビュー、VIP、同期視聴。
- ロビー機能は追加しない。
- 花火は通常手持ちのみ。打ち上げ花火は初期禁止、オーナーが明示許可した場合のみ。
- パーティーは歩行なし。会場位置クリックでプロフィールアイコンを移動。ダンス中だけ全身アバターを表示し、停止後はアイコンのみ。
- ポップコーン投げはオーナー許可制。受け取り側が拒否した場合はオーナーでも上書き不可。クールダウンあり。投げても消費しない。
- コメント欄を大きく目立たせる。主要操作はコメント／食べる／ダンス。ショップ等は上部メニュー。
- 売店の無料商品はポップコーンとコーラ。Connect Pointsで他商品を購入する構想。
- 観劇中1秒につき1 Connect Point。上限到達で獲得停止。上限時に「売却」すると残高0、次の上限を+10。自動上限増加なし。
- 食品は10回の動作で完食。アイスは種類別動作、ナゲット・ポテトは10個を1個ずつ。容器入り食品は中身レイヤーを減らし容器を残す。
- 食べ終わった容器等が一時表示後に消えた時+10ポイント（上限超過不可）。
- アイスバーのみ完食時10%で当たり。本人+50ポイント、同じ上映の他観客それぞれ+5ポイント（上限超過不可）。コメント「〇〇さんが当たりを引きました！」。
- アプリ更新時にリセットするのはConnect Points関連データのみ。その他データは保持。更新前に警告を表示。
