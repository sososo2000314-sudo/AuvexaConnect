# AuvexaConnect Project Foundation

これは完成版アプリではなく、機能を削らずに段階開発するための初期プロジェクト土台です。

## 収録物
- `docs/SPEC_INDEX.md`：これまでの仕様の台帳
- `backend/`：Cloudflare Worker APIの最小起動基盤
- `macos/`：SwiftUI Mac起動用パッケージ骨格
- `iphone-pwa/`：iPhone PWAの初期シェル
- `connect-plus/`：Connect Plusのスコープ
