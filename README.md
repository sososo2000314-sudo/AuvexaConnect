# AuvexaConnect - Foundation Package

これはAuvexaConnectの**開発土台パッケージ**です。フォルダ構成、基本画面、ナビゲーション、モジュールの入口をまとめています。

## 重要
- このZIPをGitHubリポジトリのルートにアップロードしてください。
- 既存ファイルを置き換える場合は、先にバックアップしてください。
- この段階ではログイン、データベース保存、動画アップロード、チャット、通話、プッシュ通知、管理者操作などは完成していません。
- `wrangler.toml` のD1設定は、接続先の database_id を確認してから設定してください。
- 本番公開前に認証・権限確認・入力検証・データベース処理を実装する必要があります。

## 含まれるもの
基本HTML/CSS/JavaScript、画面ナビゲーション、Cloudflare Workerの静的配信入口、機能別JSファイル、CSS分割、今後のサーバー・DB用フォルダです。
